## Potential incidents

Examples include a lost laptop, suspicious login prompt, accidentally shared confidential file or unexpectedly exposed service.

<Steps>
  <Step title="Protect yourself">Stop interacting with suspicious content. Do not attempt unapproved forensic actions.</Step>
  <Step title="Report promptly">Contact the official security reporting point through an approved channel.</Step>
  <Step title="Describe the facts">Include what happened, when it was noticed, systems affected and immediate impact.</Step>
  <Step title="Follow instructions">Preserve evidence and support the designated response team.</Step>
</Steps>

<Warning>If personal data might be affected, involve the designated privacy or incident response owners under the real company process. Do not infer notification requirements from this demo.</Warning>

## Sample report fields

| Field | Description |
| --- | --- |
| Detection time | When the issue was first noticed |
| Affected service | System, device or account |
| Observation | Factual description without speculation |
| Immediate actions | Steps already taken |
| Contact | How the response team can follow up |
