## Before you write

Check whether a page already exists, identify the audience and confirm the right information owner.

<Steps>
  <Step title="Choose a clear title">Use task-oriented language such as “Request software access”.</Step>
  <Step title="Lead with the answer">Explain the intended outcome before details.</Step>
  <Step title="Provide steps">Use numbered instructions for sequences and tables for comparisons.</Step>
  <Step title="Assign an owner">Record the reviewer and an appropriate next review date.</Step>
</Steps>

## Review checklist

- [ ] Title and summary match the content
- [ ] Instructions are complete and actionable
- [ ] Links work and use descriptive labels
- [ ] No credentials, personal information or confidential data
- [ ] Relevant policy owner has approved the content
