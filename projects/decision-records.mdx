<Note>**Sample content:** This is a lightweight decision log format.</Note>

Use a decision record when a choice affects multiple teams, introduces cost or changes a recurring process.

## Example decision record

| Field | Example |
| --- | --- |
| ID | ADR-001 |
| Status | Proposed |
| Title | Standardize internal documentation |
| Owner | Documentation lead |
| Date | To be agreed |
| Context | Knowledge is spread across different tools |
| Options | Central wiki, shared files, project trackers |
| Decision | Pending review |
| Consequences | Migration effort, ownership and access control |

## Decision lifecycle

- **Proposed:** Open for feedback.
- **Accepted:** Approved and current.
- **Superseded:** Replaced by a newer decision.
- **Rejected:** Considered but not adopted.
