<Note>**Sample workflow:** Actual project governance may differ.</Note>

## Project stages

<Steps>
  <Step title="Intake">Define the problem, expected outcome, key stakeholders and constraints.</Step>
  <Step title="Planning">Agree on scope, deliverables, owner, timeline and risks.</Step>
  <Step title="Delivery">Track progress, document changes and escalate blockers.</Step>
  <Step title="Review">Confirm acceptance criteria and lessons learned.</Step>
  <Step title="Handover">Transfer ownership, documentation and operational responsibilities.</Step>
</Steps>

## Suggested project brief

| Section | What to capture |
| --- | --- |
| Objective | Why the work matters |
| Scope | Included and excluded work |
| Owner | Accountable person |
| Milestones | Major checkpoints |
| Dependencies | Teams, tools and approvals |
| Risks | Potential blockers and mitigation |
| Success metric | How outcomes will be evaluated |
