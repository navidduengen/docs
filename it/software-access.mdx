## Request new access

<Steps>
  <Step title="Identify the service">Provide the exact application and requested role.</Step>
  <Step title="Explain the need">Describe the work that requires access.</Step>
  <Step title="Get approval">The accountable owner checks business need and least privilege.</Step>
  <Step title="Confirm activation">Verify access without sharing credentials.</Step>
</Steps>

## Access review principles

| Principle | Expected behavior |
| --- | --- |
| Least privilege | Grant only permissions needed |
| Separation of duties | Avoid conflicting responsibilities |
| Time-bound access | Set an expiry for temporary assignments |
| Offboarding | Remove access when no longer required |
| Traceability | Record approvals and changes |
